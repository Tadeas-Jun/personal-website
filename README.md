# Portfolio Website (tadeasjun.com)
🪐 The *tadeasjun.com* domain contains a small portfolio website for Tadeas Jun coded in Bootstrap in early 2023. **This repository is private.**

## Ignored files (.gitignore)
The `.gitgnore` file contains the `/assets/css/` folder, which should be autogenerated by Sass (the project initially used version `1.57.1 compiled with dart2js 2.18.6`); the `/bootstrap/` folder, which is the source code for Bootstrap (version `5.3.0-alpha1`); the `/_site/` folder, which should be autogenerated by 11ty (the project initially used version `2.0.1`).

## Adding a new project card
In order to change or add a new project card, the following checklist should be followed:

 1. The **image source** should be updated.
 2. The **image alt** tag should be updated to reflect the image.
 3. The **type icon** should be updated.
 4. The **title of the type icon** should be updated to reflect the project type ('Worldbuilding Project' / 'Coding Project' / 'Writing Project').
 5. The **title of the card** should be updated to contain the title of the project.
 6. The **body of the card** should be updated to contain a short description of the project.
 7. (optional) The **primary button** should be updated to reflect the primary action of the project.
 8. (optional) The **secondary button** should be updated to reflect the secondary action of the project.
 9. (optional) The **project modal** should be added or removed.
 10. (optional) The **modal icon** should be updated to match the type icon.
 11. (optional) The *title of the modal icon* should be updated to match the type icon title.
 12. (optional) The **title of the modal** should be updated to match the card title.
 13. (optional) The **body of the modal** should be updated with a longer description of the project.
