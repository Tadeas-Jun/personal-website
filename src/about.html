About me

Hi, I'm Tadeas! I'm a senior software engineer based in Brno, Czech Republic. I create websites from start to finish, both commercially and as a hobby. The homepage of this website contains my portfolio, so I would refer you to that if you're looking for a web developer. This page is written in a more informal style, and is meant for visitors of my website that aren't necessarily looking for engineers to hire.

In my day-to-day, I mostly go by Tad, so you can call me that! I like tinkering, which is how a lot of my personal projects started, including my largest website, Art Prompts, and my most popular one, HKSkins. In that vein, I also run a homeserver where I self-host a bunch of various open-source services, for personal and professional use. On this website, I write a small blog about tech and whatever comes to mind on a given week.

I love literature, having studied literary analysis for my Bachelor's and Master's degree. I'm interested in queer representation and post-colonial literatures. My top recommendation is Split Tooth by Tanya Tagaq.

I put a lot of emphasis on community -- in my personal life, I value my friends and everyone else around me, and I try to reflect this value in my projects, which always try to improve the lives of people.
