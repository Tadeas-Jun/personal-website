[JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript/) is my favorite programming language; while it doesn't utilize very useful features that object-oriented programming languages use, JS is quick and easy to pick up, while also at this point mature enough for long-term production projects.

I'm used to working with JS frameworks such as [React](/technologies/react), [Gatsby](/technologies/gatsby), or [Express](/technologies/express), but I make sure to keep up with vanilla JavaScript updates and keep my skills sharp: I believe a deep understanding of the language is crucial to building sustainable projects without accruing a lot of tech debt.
