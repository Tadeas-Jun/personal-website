[Ghost](https://ghost.org/) is an open-source content management system (CMS) created as a simple alternative to WordPress. I have worked with WordPress on several projects in the past, and I've always found the ecosystem a bit cumbersome, with theme development especially complicated and lacking good documentation. Because of this, I've learned to work with Ghost and now recommend using this CMS to all clients who need to be able to quickly and easily edit their pages and posts. Below are some project that I've used Ghost with.

## Brno English Speaking Theater (BEST)
I developed the small website for BEST, an amateur English-speaking theater group in Brno, Czech Republic. In this project, I created the Ghost Theme for the website, set up self-hosting and administration, and wrote extensive user guides for the clients. They found using Ghost very easy and intuitive, and don't have to worry with complicated plugin setup and maintenance like they would with WordPress.

## Eledris blog
The Eledris blog is my personal site where I write about worldbuilding and creative writing. In its current version, it runs on WordPress, but whenever I have a spare weekend, I'm working on a complete revamp in Ghost!
