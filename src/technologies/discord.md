The [Discord API](https://discord.com/developers/docs/) allows developers to create bots that enhance Discord users' experiences with the platform. Some of my earliest freelance projects were Discord bots, personalized for server admins, to help foster small communities. Since then, I've worked on bots that are actively used in thousands of servers, gaining deep knowledge of the inner workings of the API.

I predominantly work with the [Discord.js](https://github.com/discordjs/discord.js) library, but I also have experience with [Discord.js-light](https://www.npmjs.com/package/discord.js-light), [DiscordPHP](https://github.com/discord-php/DiscordPHP), [Discord.py](https://github.com/Rapptz/discord.py), and interacting with the API directly. Some of my notable projects include the [Art Prompts Discord bot](https://artprompts.app/discord-bot/), currently used on almost 8&nbsp;000 servers, several personalized moderation bots, and [Palletey](https://github.com/Tadeas-Jun/Palettey), a color palette generation bot.

![Screenshot of a Discord chat with the Art Prompts Discord bot sending several random prompts into it.](/assets/img/screenshots/screenshot-artpromptsdiscord.png)

Besides complex moderation functionalities, I've worked on implementing localized slash commands, OAuth2, sharding in production, command permissions, integrations with website dashboards, and many more advanced features.
