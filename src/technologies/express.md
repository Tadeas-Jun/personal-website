[Express.js](https://expressjs.com/) is a Node.js framework often used for implementing REST APIs. It's my go-to technology for working with back-end in JavaScript. I used it to implement the internal API for the Art Prompts project; during development of that API, I learned how to work with Express to create complex REST APIs implementing various authentication and authorization middlewares.
