All of my personal and professional projects use [git](https://git-scm.com/) for version control. For personal projects, I mainly use a self-hosted instance of [Gitea](https://about.gitea.com/), while in professional projects, I have extensive experience with both [GitHub](https://github.com/) and [Bitbucket](https://bitbucket.org/).

## CI/CD
Besides using git for version control, I've also implemented CI/CD (continuous integration / continuous delivery) pipelines using [GitHub Actions](https://github.com/features/actions). Using this technology, me and teams I work with can release new versions of production websites by simply merging a feature into the main branch of a repo.

I've implemented such pipelines in, for example, [Art Prompts](https://artprompts.app/), where I use my CI/CD processes to release new versions of not just the website, but also the internal API and Discord bot.
