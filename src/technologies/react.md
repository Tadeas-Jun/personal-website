[React](https://react.dev/) is *the* modern front-end development library. I started using it once I've learned vanilla JavaScript well enough to have a solid basis to build on. Since then, almost all of my projects use React in one way or another, usually through a framework built on top of it, such as [Gatsby.js](/technologies/gatsby) or [Next.js](/technologies/nextjs).

## Art Prompts
[Art Prompts](https://artprompts.app/) is my biggest personal project. Its front-end, a web app used by artists to get the inspiration they need to draw every day, is coded in Gatsby, a React-based framework. The website consists of complex component structures, not only for user-facing web pages, but also several admin-only dashboards used for interacting with the database using my internal API.

![A screenshot of the homepage of Art Prompts, containing a large text saying 'Draw a four-leaf clover with raindrops on it.' Below the text is a 'New prompt' button and several illustrated buttons standing for various categories of prompts.](/assets/img/screenshots/screenshot-artprompts.png)

## HKSkins
[HKSkins](https://hkskins.art/) is another website I've created in Gatsby using React. The website displays player-created skins for the video games *Hollow Knight* and *Hollow Knight: Silksong*. The website quickly became very popular and its clear, intuitive, and uncluttered UI draws thousands of visitors a day.

![A screenshot of the HKSkins website, showcasing a grid of skins for the game Hollow Knight.](/assets/img/blog/hkskins-screenshot1.png)

## Trezor
Trezor is a non-profit project I lead in 2025 and 2026, creating a digital archive for academic works in Next.js, another React-based framework. The front-end for this project implements clear, structured data visualizations and complex filtering logic.

![The homepage of the Trezor website, a neobrutalist pink digital archive search page.](/assets/img/screenshots/screenshot-trezor.png)
