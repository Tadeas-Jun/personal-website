[Eleventy](https://www.11ty.dev/) is a static site generator created to be very lightweight and simple to use. I created this portfolio website with Eleventy, allowing me to manage the contents on this site (including blog posts) via Markdown files. The website uses 11ty's quality-of-life features such as shortcodes and templates, utilizing the Nunjucks templating language.
